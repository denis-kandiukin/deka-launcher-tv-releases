# Формат `version.json`

Лаунчер раз в сутки (если не отключено) и по кнопке «Проверить» запрашивает:

```
https://github.com/denis-kandiukin/deka-launcher-tv-releases/releases/latest/download/version.json
```

Файл прикладывается к каждому релизу вместе с APK. GitHub отдаёт его из последнего релиза, не помеченного как pre-release.

## Пример

```json
{
  "versionCode": 20,
  "versionName": "0.11",
  "apk": "https://github.com/denis-kandiukin/deka-launcher-tv-releases/releases/download/v0.11/DEKA-LauncherTV-v0.11.apk",
  "sha256": "bab536ee2061397864501ea0bdc0d082607a4bb9a54ab5cc4fc728bc6385498e",
  "size": 9017101,
  "minSdk": 28,
  "notes": [
    "Обновления изнутри лаунчера",
    "Журнал сбоев на телефон по QR"
  ]
}
```

## Поля

| Поле | Тип | Обязательно | Смысл |
|---|---|---|---|
| `versionCode` | целое | да | Номер сборки. Обновление предлагается, только если он больше установленного |
| `versionName` | строка | да | Версия для людей: «0.11» |
| `apk` | строка | да | Прямая ссылка на APK, `https://` |
| `sha256` | строка | да | SHA-256 файла APK, 64 hex-символа, регистр не важен |
| `size` | целое | нет | Размер в байтах — для процента загрузки |
| `minSdk` | целое | нет | Минимальный Android (SDK). Если на ТВ ниже — версия не предлагается |
| `notes` | массив строк | нет | «Что нового» — показывается перед установкой |

## Что проверяет лаунчер

1. `versionCode` больше установленного и `minSdk` не выше Android на ТВ.
2. После загрузки — SHA-256 файла совпадает с `sha256`.
3. Пакет — `ru.dekan.tvlauncher`, подпись совпадает с установленной версией.
4. Установку подтверждает пользователь в системном окне Android.

Если хотя бы одна проверка не прошла, файл удаляется, а пользователь видит причину.
