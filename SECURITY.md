# Безопасность

## Поддерживаемые версии

Исправления выходят только для последней версии. Обновляйтесь из лаунчера: *настройки → «О лаунчере» → «Обновления»*.

## Как сообщить об уязвимости

Не публикуйте подробности в открытых issue. Используйте приватный канал GitHub: вкладка **Security → Report a vulnerability** этого репозитория.

Опишите, пожалуйста:
- версию лаунчера и модель ТВ / версию Android;
- что именно уязвимо и как это воспроизвести;
- к чему это может привести.

Ответ — в течение 7 дней. После исправления уязвимость будет описана в заметках к релизу.

## Что считается уязвимостью

- утечка токена Home Assistant, ключа DEKA Pro или других данных с ТВ;
- выполнение команд в Home Assistant без участия пользователя;
- установка через механизм обновлений APK, не подписанного ключом DEKA;
- доступ к одноразовым страницам ввода (QR) извне домашней сети.

## Модель доверия

- Обновление ставится, только если SHA-256 файла совпадает с `version.json` **и** подпись APK совпадает с установленной версией; финальное подтверждение — системное окно Android.
- Страницы ввода токена и ключа по QR открываются только в локальной сети, по случайному коду, на 5 минут.
- Токен Home Assistant хранится зашифрованным через Android Keystore.
